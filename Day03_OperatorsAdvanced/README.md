# Day 03 - 运算符进阶 + 位运算应用

## 核心知识点

### 1. 移位运算符（4 种）

| 运算符  | 含义                       |
|---------|----------------------------|
| `a << n`  | 逻辑左移，低位补 0         |
| `a >> n`  | 逻辑右移，高位补 0         |
| `a <<< n` | 算术左移（同 `<<`，结果一致）|
| `a >>> n` | 算术右移，高位补**符号位**（操作数必须 `signed`，否则同 `>>`）|

```verilog
wire signed [7:0] a = 8'b1010_1100;  // -84
a >>> 3  // → 8'b1111_0101  （补符号位 1）

wire [7:0] b = 8'b1010_1100;         // 无符号，172
b >>> 3  // → 8'b0001_0101  （补 0，与 >> 相同）
```

**规范**：无符号数移位用 `<<` / `>>`，不要用 `<<<` / `>>>`，避免歧义。

---

### 2. 拼接 `{,}` 与复制 `{N{x}}`

```verilog
{a, b}              // 拼接（左为高位）
{ {8{data[7]}}, data }  // 把符号位复制 8 次 → 符号扩展
{8{1'b1}}           // = 8'hFF
```

- 拼接类比 C++ `string + string`，但操作 bit
- 复制 `{N{x}}` 类比 `std::string(N, c)`

---

### 3. 三种"与"的本质区别（核心，面试高频）

| 运算符  | 类型   | 结果位宽       | 类比 C   |
|---------|--------|---------------|----------|
| `a & b` | 按位与 | 与操作数同宽   | `a & b`  |
| `a && b`| 逻辑与 | **1 位**       | `a && b` |
| `&a`    | 缩位与 | **1 位**（全 1 才输出 1）| 无 |

同理：`|` vs `||` vs `|a`（任一位为 1 则 1），`^a`（奇偶校验），`!` vs `~`。

**口诀**：
- 做硬件 AND 门 → `&`
- 做 if 条件 / 判断真假 → `&&`
- 看 bus 是否全 1 / 有没有 1 / 奇偶 → `&a` / `|a` / `^a`

---

### 4. 比较运算符

`==` `!=` `>` `<` `>=` `<=` 全部返回 **1 位**结果，同 C。

## 练习情况

| 题号 | 主题               | 结果 | 说明 |
|------|--------------------|------|------|
| 1    | 可变位数左移器     | ⚠️   | 用了 `<<<`，应用 `<<`，结果对但不规范 |
| 2    | 8→16 符号扩展      | ❌   | 写成零扩展 `{8'b0, data}`，正确：`{ {8{data[7]}}, data }` |

| 4    | 32-bit 字节序反转  | ✅   | 一行拼接，切片范围全对 |
