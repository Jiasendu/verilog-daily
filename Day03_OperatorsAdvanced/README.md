# Day 03 - 运算符进阶 + 位运算应用

## 核心知识点

### 1. 移位运算符
| 运算符 | 含义 |
|---|---|
| `a << n`  | 逻辑左移，低位补 0 |
| `a >> n`  | 逻辑右移，高位补 0 |
| `a <<< n` | 算术左移（同 `<<`） |
| `a >>> n` | 算术右移，高位补符号位（操作数必须 `signed`） |

### 2. 拼接 `{,}` 与复制 `{N{x}}`
```verilog
{a, b}              // 拼接（左边为高位）
{ {N{x}}, data }    // 把 x 复制 N 次再拼接 —— 常用于符号扩展
{8{1'b1}}           // = 8'hFF
```

### 3. 三种"与"的本质区别（核心）
| 运算符 | 类型 | 结果位宽 |
|---|---|---|
| `a & b` | 按位 | 与操作数同宽 |
| `a && b` | 逻辑（判真假） | 1 位 |
| `&a` | 缩位（全 1 才 1） | 1 位 |

同理 `|` vs `||` vs `|a`，`!` vs `~`。

### 4. 比较运算符
`==` `!=` `>` `<` `>=` `<=` 都返回 1 位结果。

## 练习题

| 题号 | 主题 | 结果 |
|---|---|---|
| 1 | 可变位数左移器 | ⚠️ 用了 `<<<`，应用 `<<` |
| 2 | 8→16 符号扩展 | ❌ 写成零扩展，正确：`{ {8{data[7]}}, data }` |
| 3 | 逻辑/按位/缩位 综合判断 | ✅ |
| 4 | 32-bit 字节序反转 | ✅ |

## 反思
- 三种"与"的辨析过关
- 拼接/复制熟练，字节翻转一行搞定
- 持续问题：动笔前不验证输入输出，导致练习 2 把符号扩展写成零扩展
