# Day 05 - 基础语法收尾：优先级编码器 & casez

## 核心知识点

- `if-else if` 链综合为优先级树，越靠前优先级越高
- `casez` 用 `?` 表示无关位，匹配顺序即优先级
- 避免 `casex`（把 `x` 当无关位，会掩盖仿真 Bug）
- `!`（逻辑非）vs `~`（按位取反）：判断非零用 `!` 或缩位 `|data`
- 多语句分支必须用 `begin...end`
