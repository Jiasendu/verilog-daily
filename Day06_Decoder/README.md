# Day 06 - 组合逻辑：译码器（Decoder）

## 核心知识点

- 译码器：n 位输入 -> 2^n 位独热输出
- 独热输出可用移位：assign y = en ? (1 << sel) : 0
- 不规则输出（七段数码管）用 case 枚举
- 组合逻辑 always @(*) 必须用 = 阻塞赋值
- case 必须有 default，防止推断 latch
- wire 用 assign；reg 在 always 里赋值
