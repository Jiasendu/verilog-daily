# Verilog Daily 📘

我的 Verilog 学习日志，目标是为之后学习 SystemVerilog 打下扎实基础。

> 🤖 **本项目由 Claude (Anthropic) 协助完成学习。** 如需用新的 Claude 窗口接续学习，请直接复制 [`CLAUDE_PROMPT.md`](./CLAUDE_PROMPT.md) 中的 prompt 发给 Claude。

## 🎯 学习路线

- **第一阶段·基础语法（Day 1-5）**：模块结构、数据类型、运算符、assign、always
- **第二阶段·组合逻辑（Day 6-10）**：MUX、译码器、编码器、加法器、ALU
- **第三阶段·时序逻辑（Day 11-16）**：触发器、寄存器、计数器、分频器、移位寄存器
- **第四阶段·进阶（Day 17-22）**：FSM、存储器建模、流水线、Testbench
- **第五阶段·综合项目（Day 23+）**：UART、SPI、简单 CPU
