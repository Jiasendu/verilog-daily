1. 基础语法（Day 1-5）：模块、数据类型、运算符、assign、always（已完成）
2. 组合逻辑（Day 6-10）：MUX、译码器、编码器、加法器、ALU（进行中）
3. 时序逻辑（Day 11-16）：触发器、寄存器、计数器、分频器、移位寄存器
4. 进阶（Day 17-22）：FSM、存储器建模、流水线、Testbench
5. 综合项目（Day 23+）：UART、SPI、简单 CPU
